**Video-Conferencing-Platform** <br/>
This Video Conferencing Platform is a real-time communication solution that enables users to host and join secure virtual meetings from anywhere.<br/>
It supports high-quality video, audio, screen sharing and chat messaging..<br/>

**Features:** <br/>

🎥 HD Video & Audio Calls<br/>
👥 Multi-Participant Meetings<br/>
💬 Real-Time Chat Messaging<br/>
🖥️ Screen Sharing<br/>
🎙️ Mute / Unmute Controls<br/>

**🧰 Tech Stack-** <br/>

- **BACKEND:** <br/>

- Bcrypt<br/>
- crypto<br/>
- Socket<br/>
- Express.js<br/>

- **FRONTEND:** <br/>
- Material UI<br/>
- WebRTC<br/>
- CSS<br/>
- react<br/>
- Axios<br/>

- **DATABASE:** <br/>
- MongoDB<br/>

Steps to Run Locally-<br/>
1️⃣ Clone the Repository:<br/>
```
git clone https://github.com/HarshitaJain10/Video-Conferencing-Platform.git
cd Video-Conferencing-Platform
```
2️⃣ Install Dependencies:<br/>
```
npm install
```
3️⃣Run the Application:<br/>
```
npm start
```
